# 宝石 TD 手机试玩版

单人 2D 棋盘塔防。当前为 Alpha：可以建造、留石、融合、合成、防守、结算和续玩；不应视为已完成 DOTA 2 原版还原或后期平衡验收。

当前alpha-6补全隐藏合成资格、随机塔属性、技能复制、弹道与持续技能、怪物能力、八类三级石板及51–100波挑战。实现、来源与尚存差异见[补全记录](docs/mechanics-restoration.md)。

第10波Boss已按用户确认调整为800生命；正在第10波战斗的旧存档，恢复时按剩余血量比例折算。原始来源保留1260的历史单人值，详见[Boss调整记录](docs/boss-audit.md)。

## 本地运行

需要 Node.js 22.13 或更高版本，使用 npm。

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

打开终端打印的本地地址。同一局域网的安卓手机可尝试通过电脑局域网 IP 与该端口访问；需网络和防火墙允许。正式试玩以部署地址为准。

```sh
npm run typecheck
npm test
npm run balance:check
npm run build
```

## 存档与界面

手机自动进入触屏模式，默认完整显示地图，不常驻底部或右侧操作面板。点选空格、石头或宝石，再点“操作”打开弹窗，进行建造、保留、融合或配方合成；完成后自动回到地图。建造框保留逐格微调，合成框提供材料槽和坐标列表。双指缩放，放大后可拖动；暂停、倍速、宝石列表、图鉴及模式切换均在右上角菜单中。详见[交互设计与测试](docs/touch-interaction.md)。

选中石头可直接“替换建造”，无需先拆除；桌面侧栏提供相同入口。替换使用正常随机品质，占用本轮一次建造次数，位置与道路占用不变；只在准备阶段且次数未用完时可操作，已有宝石不能被覆盖。

存档仅在当前浏览器本地保存，不跨设备同步。每次有效操作、波次切换和战斗约5秒间隔保存；恢复后暂停。alpha-6可迁移alpha-3/4/5，alpha-5保留MVP与统计。旧版缺少的随机攻击/复制技能在迁移时初始化一次，之后不重抽；详见补全记录。其他不兼容版本仍拒绝。

建满五颗后点击“保留并开始本波”，立即留石并开始当前波次。战斗中仍可选中已保留宝石进行配方合成，手选材料后确认，其余材料原地变石；预览期间暂停，确认或取消恢复此前状态和倍速。

2级及以上本轮候选可选“敲碎并保留”：随机降级，越接近原品质的概率越高，种类与位置不变，其余候选变石，随后自动开波。1级不可敲碎，操作框直接显示各结果概率。详见[敲碎规则与验证](docs/crushing.md)。

前50波按逐笔取整伤害计分，最高且未满级的塔获得1级MVP；每级攻击伤害+10%，并提供6.25格范围每级数值7的减魔抗。满级为周围2.265625格圆形范围内其他塔增加100%攻击伤害；多个满级来源叠加。满级退出评选，合成继承材料等级总和、最高10级，成品本波从零计分。51–100波保留已有MVP，不再升级。右上角可查看每波逐塔伤害，见[MVP规则与验证](docs/mvp.md)。

React 界面以低频显式刷新读取可变模拟状态，Phaser 独立绘制。该桥接组件明确退出 React Compiler 自动记忆化；规则层保持不依赖 React。未来可将桥接进一步拆成 external store，但不可直接给可变状态套用自动记忆化。

## 已知边界

- 数据基于 2018 年非官方提取快照，并非当前地图版本。
- 已补全主要脚本机制、石板和隐藏获取条件；历史引擎的护甲、减抗、不同等级减益叠加和免疫来源结算仍有待核验，详见补全记录。
- 地图按两套社区工具恢复单人布局；原Lua已确认128单位/格。品质经验与概率、动态出怪数量、奖励和漏怪伤害已按2018脚本校准，详见[核对与测试报告](docs/original-rules-audit.md)。
- 尚未完成安卓真机交互和性能验收，未制作 APK。
- 后期难度尚未证明合理；不要将自动测试中用于检查胜利状态的超高伤害夹具当作正常通关结果。
- 验证记录随版本保存在补全记录中；公开版本通过GitHub Actions发布。`npm run data:original` 可重建基础事实，`scripts/extract-mechanics.mjs`提取本轮新增事实。

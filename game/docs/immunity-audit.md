# 免疫、混合伤害与第23波核查

日期：2026-09-08。运行版本：`d6ba5b5`（alpha-4-mvp）。原始脚本：2018-06-10固定提交 `712f6a2d0f68ea4049e8923917311f8d1a44dfc8`。

后续实现更新：alpha-5已恢复MVP攻击增幅与敌方减抗，并增加每波分类统计，见[MVP与统计](mvp.md)。下文实验和“108/秒”等结果仍是旧alpha-4快照，不代表新版输出；逐技能免疫及历史引擎结算疑问仍待验证。

用户反馈：记忆中铀235在物免波、古代鸡血石在魔免波仍有高额伤害；本次满MVP星彩、大孔雀、两座白银在第23波7200血敌人面前失败。尚未拿到本局地图、完整塔等级及敌人数量，也未确定用户回忆的游廊版本。以下区分源码事实、当前模拟器复核和待证实问题。

后续用户明确确认整波对应免疫、没有其他技能时仍有伤害。[全免疫波追查](immunity-followup.md)核实统计是减免后事件值；已排除混合波、英雄链接等外部增益。铀附加箭是Lua伤害而非新普通攻击，Shock未传技能对象，不能只凭伤害类型与KV断言完整免疫路径。具体原因仍未唯一确定，现版统一归零模型待验证。

## 结论

1. 固定快照的物免确实是物理承伤−100%。它没有把怪物变成不可攻击或无敌，因此仍可触发攻击命中特效；特效按自己的伤害类型和选敌条件结算。白银骑士的纯粹溅射就是例子。
2. 魔免有两个维度：技能能否生效、伤害如何减免。`enemy_momian`同时赋予魔法免疫状态和+100魔抗；`enemy_jimian`只赋予状态。“技能伤害”不等于“魔法伤害”。
3. 本次没有找到铀235固有技能穿透物免、古代鸡血石高额法术穿透魔免的完整源码证据。铀附加箭明确是物理，古代鸡血石闪电及灼烧明确是魔法，普攻另属物理。结论限定于固定快照的固有技能；外部增益和Lua调用路径需另查，不能否定实战中的伤害归属或其他游廊版本的实际体验。
4. 若两座塔是基础白银，列出的阵容在当前物免波中主要只剩星彩灼烧。满MVP且无其他增益时，每只怪108伤害/秒，烧完7200血需累计约66.7秒接触。
5. 原MVP包含敌方减魔抗光环，与现版用户指定的全伤害加成、八格友方光环不等价。灼烧离圈后的残留也未模拟。血量正确不等于整体难度已还原。

## 第23波伤害断档

按基础白银解释阵容，且星彩只有自身MVP10、没有额外光环或减魔抗：

```text
基础灼烧 = 30 / 0.5 = 60 / 秒
当前实际灼烧 = 60 × (1 + 100%) × (1 − 10%) = 108 / 秒 / 怪
7200 / 108 = 66.67 秒累计受伤
```

大孔雀、基础白银的物理输出为0，友方MVP光环不能使其产生非零伤害。两座白银可以改善减速覆盖，但同技能−90不叠成−180；当前优先打最前敌人，也可能集中同一目标。

星彩灼烧直径6.25格。假设一直保持白银减速，速度`(552.5−90)/128 = 3.6133格/秒`，直线过圆心一次约1.73秒；六次累计约10.38秒，连续近似预算1121伤害。**这不是任意迷宫的伤害上限**：范围内绕行、额外控制、其他伤害塔都会改变结果，也未计离散灼烧相位及历史残留。

如果实际是白银骑士，50%纯粹溅射可以参与物免波输出，不能套用“只有星彩有伤害”。完整塔等级、已漏生命、出怪数量和布置未知，未声称复现整局败局。

## 差异、限制与后续

- 原MVP的敌方减魔抗是区域辅助，会影响附近其他法术塔。现版是用户指定的全伤害和八格光环；不是原脚本的等价搬运。原1–9级按等级使用不同修饰器名称，10级明确MULTIPLE；真实叠加、魔抗公式及伤害百分比作用范围仍需历史客户端验证，不能将−70代入现版公式后宣称原版DPS。
- 当前灼烧离圈即停止，缺少历史持续修饰器。按几次直线穿越估算，单凭一秒残留也不足以解释基础星彩迅速烧完7200血。
- 当前魔免未完整表达逐技能穿透权限：例如普通紫晶和黄金原配置Flags不同，现版统一施加减甲。需要逐技能矩阵，不能一律放行或封死所有技能。
- 新取得Shock证实实际为主目标加1000单位范围附加目标。现版取主目标周围10格内前5只、未保证主目标入选，范围也更大。这是执行差异，不能解释没有古代鸡血石的这局23波失败。
- 本次没有找到新版官方源码证明用户回忆的两种穿透。工作坊[更新记录](https://steamcommunity.com/sharedfiles/filedetails/changelog/474619917)虽有后续修复，简短说明不足以还原免疫矩阵。其他Unity、网页、魔兽、独立手游同名作品不作为目标版本证据。

本轮保存研究，不降低生命或改写已确认的MVP设计。优先对应用户所玩版本及基础白银/骑士信息，再决定需要还原的历史机制或当前自定义规则的平衡调整。

## 后续追查：钻石的额外伤害是否穿物免

2026-09-08用户进一步提出：钻石的额外伤害被动是否提供穿物免能力，所有拥有它的塔是否都因此能穿物免。

**固定快照不支持这个推论。** [技能配置3756–3890行](https://github.com/clementbera/Website/blob/712f6a2d0f68ea4049e8923917311f8d1a44dfc8/GemTD-Generation/scripts/npc/npc_abilities_custom.txt#L3756)中的`tower_attack1`至`tower_attack7`全部是基础攻击力属性加成，唯一伤害相关属性为`MODIFIER_PROPERTY_BASEATTACK_BONUSDAMAGE`，分别增加20、40、80、160、320、640、1280。其修饰器没有攻击命中事件、额外ApplyDamage、魔法/纯粹伤害触发或伤害类型转换。

这些技能虽然借用海民海象神拳的图标，但BaseClass为普通数据驱动技能；图标并不赋予海象神拳的机制。基础攻击力加成也不同于单独触发纯粹伤害的`PROCATTACK_BONUS_DAMAGE_PURE`属性。

| 代表塔 | 被动 | 基础值＋加成 | 另有明确可对物免输出的伤害部分 |
| --- | --- | ---: | --- |
| D4无暇钻石 | attack1 | 20＋20＝40 | 此快照没有 |
| D5完美钻石 | attack2 | 40＋40＝80 | 此快照没有 |
| D6巨大钻石 | attack5 | 140＋320＝460 | 此快照没有 |
| 粉红钻石 | attack3 | 30＋80＝110 | 另有暴击，但暴击不改变物理类型 |
| 铀235 | attack4 | 60＋160＝220 | 多重箭Lua仍明确指定物理类型 |
| 巨型粉红钻石 | attack4 | 150＋160＝310 | 另带jianshe3：50%纯粹溅射 |
| 黑曜石 | attack6 | 180＋640＝820 | 另带jianshe5：70%纯粹溅射；其他未还原技能不据此推断 |
| 虾美石 | attack6 | 585＋640＝1225 | 另有魔法闪电；其他技能需分别核查 |

无暴击、MVP或其他增益时，巨型粉红钻石的310点物理伤害被物免拦截，而纯粹溅射的名义值为310×50%＝155。额外攻击力可以间接提高这段溅射，但穿物免的原因是**额外存在纯粹溅射技能**，不是attack4本身。

已对当前使用的13种含`tower_attack`被动的塔核对：基础钻石3种、粉钻系列3种、铀系列2种、金刚石库利南、黑曜石、玛瑙、虾美石、镇家之石。现版已将额外值加入攻击力，并非漏掉被动数值；是否另有法术、纯粹或未还原特殊技能仍逐塔判断，不能从共有的加攻被动推定穿免疫。上述说明是静态源码结论，未在用户所玩版本的Dota客户端进行实验。

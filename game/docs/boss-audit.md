# Boss 数值依据核查

核查日期：2026-09-08。检查对象为提交 `cb52ef3` 的游戏代码，数据版本 `2018-source-mobile-alpha-4-mvp`。本轮只补充核查文档，未修改游戏数值或机制。

## 结论

前50波的五个默认 Boss，其基础生命、移动速度、护甲和魔抗均有保存的2018脚本依据，未发现抄录或单人缩放错误。实际出怪属性、每波1只、击杀300经验/150金币和按剩余生命扣城堡血的计算也通过逐项检查。

这能证明与所选历史基线一致，不能证明等于现在的工作坊版本，也不能证明无英雄、加入MVP后的当前版本已经平衡。第40/50波的海妖外壳、原版随机替代Boss、超时狂暴尚未实现，基础属性一致不代表完整战斗行为一致。

后续计算：[单人第10波Boss配置与有效输出时间](boss10-theory.md)，比较早期核心、MVP分布和射程覆盖；与本报告的来源核查分开记录。

## 缩放、数量、奖励与扣血依据

以下行号对应 `addon_game_mode.lua`：

- **单人生命×0.6，移速×0.85**：939–949行定义人数系数；2756–2757行更新人数难度；2786行计算生命，2824–2829行写入生命和速度。Boss不参与2776–2784行的普通精英随机增血。2789行起的通关后额外缩放不适用于前50波。
- **每个Boss波1只**：2901–2903行在Boss生成后减少剩余生成数，使这一波停止继续刷怪；本项目在 `startWave` 中直接将 `combatCount` 设为1，不随普通怪数量增加。
- **击杀300经验、150金币**：5512–5527行将这五波的经验设为300；5560–5563行对高额经验对应的金币减半。本项目采用这组基础奖励；没有加入原版贪婪效果等额外奖励。
- **漏怪扣血**：2859–2873行将Boss的基础扣血参数设为80；3030–3040行根据其剩余生命计算最终扣血。80是计算参数，并非每次固定扣80。

```text
已损失百分比 = floor((最大生命 - 剩余生命) / 最大生命 × 100)
城堡扣血 = floor(80 × (100 - 已损失百分比) / 100) + 10
```

因此满血漏掉扣90，剩一半扣50，剩1%扣10；击杀则不扣血且获得奖励。

## 已确认的还原缺口

1. **第40/50波海妖外壳未实现。** Lua的1177、1187行指定 `tidehunter_kraken_shell`，2770–2772行按人数添加并升级技能。因此不能只看NPC的 `Ability1` 就认定没有特殊技能。技能配置7003–7024行给出单人参数 `damage_reduction=0`、`damage_cleanse=40000`、`damage_reset_interval=10`。游戏目前只在 `Wave.notes` 保存技能ID，敌人状态和伤害结算没有执行对应效果；具体原生净化行为仍需结合当年的Dota引擎核验，不能凭技能名字补出细节。
2. **随机替代Boss未实现。** Lua的5356–5369行给第20/30/40波各10%的替代概率；第50波先独立20%判定金肉山，再独立10%判定铂金肉山且后者覆盖前者。按此顺序推得普通/金/铂金最终为72%/18%/10%。当前每次都是表中的默认Boss，`variants`为空。本表不代表这些替代Boss的数值。
3. **超时狂暴未实现。** Lua的2680–2690行在单人波次计时超过180秒后添加 `enemy_crazy`；技能配置7238–7276行写有移速百分比加成100和魔法免疫。当前引擎没有这一时限效果。
4. **引擎计算和难度仍有差异。** 护甲16这个输入值有来源，但当前物理护甲公式、最低移动速度0.35格/秒、飞行路线直连路标以及立即命中等模拟器处理，尚未逐项证明与2018引擎一致。移除英雄技能、未实现石板，以及新增可叠加MVP都会影响实际难度。当前Boss基础数值一致，不能据此断言50波已平衡。

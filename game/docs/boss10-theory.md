# 单人第10波Boss：配置与有效输出时间

计算日期：2026-09-08。下文保留以提交 `ffe7fb9`、数据版本 `2018-source-mobile-alpha-4-mvp` 为依据的1260生命历史计算。

**当前状态：用户已确认把第10波Boss生命降低到800，并已实现。** 配置、旧战斗存档转换和验证见[Boss调整记录](boss-audit.md)。下方13.8秒等击杀时间仍是调整前1260目标的历史结果，不代表800生命下的现行击杀时间；各塔的伤害、射程和已有穿越伤害预算未因这次改血而改变。

## 调整前的结论

**按用户提出的“中心最多穿越6次、第10波前迷宫未必成型”约束，1260生命作为无英雄版本的普通首Boss，要求偏苛刻；有原版出处不足以确认当前难度合理。** 有限穿越计算见下节。当时提出800作为试调起点、900作为偏难候选；用户随后选择了800，现已替代待决定状态。

此前的 **白银MVP3 + 瑕疵翡翠G2 + 瑕疵紫晶P2 + 碎裂蛋白石E1** 是连续接触下的理论核心：全体持续攻击、攻速光环覆盖时，稳定输出约94.2点/秒，当前引擎计算约13.8秒击杀。这个固定目标结果不能直接转换成第10波可实现的实战配置推荐；此前对实际迷宫成熟度的判断过于乐观。

这不是“不管放在哪里都能过”的最低塔数结论。只把同样四座塔摆在中心、保留初始石头而不额外造迷宫的对照场景，总伤害仅443.7，Boss会漏过。需要兼顾塔种、MVP和火力范围内的路径。

## 有限穿越下的平衡复评

补充日期：2026-09-08，代码仍为 `2018-source-mobile-alpha-4-mvp`。用户指出理论上最多6次穿过中心，并且第10波不一定能建成完整迷宫。本节将6次作为本次评估的上限约束，未证明它适用于任何可能的A*迷宫；每段在射程内曲折行走也会改变单次停留时间。

重新使用当前引擎计算有限次数的直线接触，保留各塔真实射程、Boss减速、负甲、攻速、普通攻击离散次数、独立毒层和每0.5秒一次的星彩灼烧。下面是路径通过核心附近的样例伤害预算，取整；这几套配置未列出的其他塔伤害不计入。

| 核心配置 | 3次穿越 | 4次穿越 | 5次穿越 | 6次穿越 |
| --- | ---: | ---: | ---: | ---: |
| G2 M3 + D2 + P2 + B2 + E1 | 471 | 630 | 786 | 944 |
| 白银M0 + G2 + P2 + E1 | 580 | 777 | 968 | 1,166 |
| 白银M3 + G2 + P2 + E1 | 673 | 903 | 1,124 | 1,354 |
| 白银M6 + G2 + P2 + E1 | 766 | 1,028 | 1,280 | 1,542 |
| 白银M3 + 星彩M3 + G2 + P2 + E1 | 985 | 1,318 | 1,643 | 1,977 |

对1260生命的含义：

- 白银MVP3四塔核心，即使6次较完整穿越，也只多出约7.5%的伤害；5次仍不足。
- 白银MVP6的核心，5次为1280，仅多出约1.6%，很依赖走位与攻击时序。
- 双核完整配置4次可以击杀，但1318只有约4.6%的余量。将相同路径向一侧平移2格后，四次伤害降到1150，无法击杀。
- 这些结果没有证明1260不可击杀：更强MVP集中、更好的布阵和核心外其他塔都可贡献伤害。但普通首Boss若需要接近完整迷宫或完整双核，随机材料和手机布阵带来的容错就很低。

因此建议以“**一座早期合成主塔、2～3座基础辅助、约4次较完整经过，具有一定击杀余量**”作为待验证的普通难度目标，而不是以理论最多6次或完整双核作为默认要求。以白银MVP3核心的样例预算903（偏离2格为883）看，800生命约留10%～13%伤害余量；900几乎没有余量。800比当前1260降低36.5%，900降低28.6%。这说明800值得先测，不证明它已经平衡；若实战只能有效经过2～3次，800仍可能偏难。

评估当时保留1260，用户随后已确认800。后续验证仍应保持速度与奖励一致，使用自然出石、前9波真实保留/合成和MVP成长的多种子完整流程，记录第10波前成型情况、实际射程接触时间、击杀率与漏怪剩余血量。几个预置场景不能替代这项验证，也不足以决定所有Boss统一缩放。

计算方法与局限：

1. 五个可用塔位依次为零基坐标(17,17)、(17,19)、(19,17)、(19,19)、(19,16)。四塔组合只用前四个位置；核心排序见表，E1覆盖所有核心塔。
2. 规定Boss沿 `y=18` 在 `x=10` 与 `x=26` 之间往返，每段外侧另留5秒空档；偏移检查用 `y=20`。在真实引擎每步结算伤害后，按Boss基础速度和当前蓝宝石/白银减速推进横坐标。这个规定路径只检查接触次数，并非由合法石头布局求得的A*路线。
3. 使用高生命探针累加总伤害，护甲、魔抗、移速和各塔伤害保持当前值，并记录何时累计达到1260。固定位置控制只用于替代引擎移动，不代表阵容获得眩晕。所选塔没有按目标最大生命计算的伤害，探针生命不会增加单次伤害。
4. 最后一段以后让已施加毒层全部结算；实战若Boss提前进终点，部分毒伤会来不及生效。因此表格是对指定接触路径的有利伤害预算，不是保证值或全局最优值。更换空档、进场相位、塔位、路径形状会改变离散攻击次数。
5. 检查5组配置×2种路径×5种次数，共50个条件场景。复查脚本为Git忽略的 `outputs/boss10-pass-budget.mjs`，结果为 `outputs/boss10-pass-budget.json`；在 `game/` 运行 `node --import tsx outputs/boss10-pass-budget.mjs`。此补充只改报告，未运行新的自然种子通关测试或修改游戏逻辑。

## 第10波开战前的限制

- 不屈战犬：生命1260、护甲0、魔抗10%、移速637.5单位/秒，即4.98046875格/秒；地面、无闪避、无物免或魔免、基础回血0。来源详见[Boss数值核查](boss-audit.md)。
- 从新局推进至第10波，前面只有9次波次结算。全场MVP等级之和最多9，合成只是转移，不凭空增加。因此第10波开战时不可能自然拥有10级MVP光环；本波奖励在Boss死亡或漏过后才发。
- 全击杀且快速过波时，第9波结束累计270经验，品质等级为Lv.2；未增加怪物数量时为225经验，同样是Lv.2。此时建造概率为1级80%、2级20%，不能提前使用击杀Boss后的升级概率。
- 2级基础宝石也能由当轮两个相同1级候选融合获得。3级及以上需要进一步融合等条件，本报告主配置不依赖这些高品质随机结果。
- 表中的MVP等级是条件，不是保证每局都能按意图分配；此前击杀伤害排名、合成继承和旧存档迁移会改变实际等级。未列出的塔和它们的伤害、MVP均不计入核心输出。

连续接触检查使用固定目标：保留Boss全部生命、护甲、魔抗，将其放在所有塔的射程内并固定位置，取消移动限制带来的接触中断。这个固定位置是计算夹具，不是推荐阵容具有无限眩晕。普通攻击起始冷却为0；实际进场时的冷却/灼烧相位会造成小幅差异，不能把小数当作任何布局下的保证。

## 白银四塔核心的计算过程

当前P2每次攻击施加4点减甲，持续2秒。Boss原护甲0，持续减甲后为−4；引擎物理倍率为：

```text
1 - 0.06 × (−4) / (1 + 0.06 × |−4|) = 1.193548…
```

E1提供20攻速，当前规则下覆盖自身和附近塔。白银/G2/E1的1秒基础攻击间隔变为1/1.2秒，P2的0.6秒变为0.5秒。白银MVP3让自身全伤害×1.3。

| 塔 | 稳定伤害构成 | 伤害/秒 |
| --- | --- | ---: |
| 白银M3 | 30 × 1.3 × 1.2 × 1.193548 | 55.86 |
| G2 | 普攻4 × 1.2 × 1.193548；每次攻击毒伤4 × 5跳 × 0.9，每秒1.2次攻击 | 27.33 |
| P2 | 4 ÷ 0.6 × 1.2 × 1.193548 | 9.55 |
| E1 | 1 × 1.2 × 1.193548 | 1.43 |
| 总计 | 毒伤已扣10%魔抗，物理伤害已算负甲增伤 | 94.17 |

解析值1260/94.17≈13.38秒；实际连续接触检查约13.83秒。白银兼具90单位/秒减速，在减速生效期间Boss速度为 `(637.5−90)/128=4.27734375格/秒`，有助于增加接触时间，但不会直接增加DPS。

其他容易算错的地方：

- 孔雀石和黄玉面对单个Boss，分裂箭只有一个目标，不能把单体输出乘3。
- 当前翡翠每次命中的5次毒伤独立叠加，不能只把G2视为“每秒4点毒”。离开射程后已有毒层仍继续结算，直到毒层结束或敌人离场。
- 星彩红宝石是每秒60点魔法灼烧，扣魔抗后54，MVP3后70.2。它没有普通攻击，蛋白石攻速和紫晶减甲不能提高其灼烧伤害。
- 星彩有效灼烧半径只有400/128=3.125格；白银攻击半径为4.6875格，G2/P2/E1为3.90625格。进入白银射程不等于进入星彩灼烧范围。
- 同级蛋白石的同ID光环不重复叠加；不同等级光环当前可叠加。Q系列自带的攻速与蛋白石攻速相加，不能把它的最终攻速再简单乘1.2。

## 路线比全程时间更关键

只有32块初始石头、没有玩家新建物时，当前A*地面路线约113.6569格，无减速的Boss约22.8205秒走完。但全程绝大多数时间可能不在主塔射程内。

一座白银射程直径9.375格。即便近似沿直径横穿、全程受到白银减速，一次穿过也只有 `9.375/4.2773≈2.19秒`，MVP3白银这一趟通常只有少数几次攻击。普通一次或两次擦过主塔，远不足以产生四塔核心约14秒的持续集火效果。

四塔核心若要约14秒持续共同输出，在持续白银减速下相当于Boss在共同火力区行进约60格；约15秒对应64格。这是可重复经过路段的累计长度，并非要求一条60格直线或恰好建60块石头。分段接触时，应分别累计每座塔的输出；短空档可能保留毒层和减益，长空档则需要重新叠毒/减甲，不能机械套用同一个时间门槛。

无额外迷宫对照：白银/G2/P2/E1分别放在零基坐标(17,17)/(17,19)/(19,17)/(19,19)，保留32块初始石头，允许真实A*绕开这四座塔，Boss正常移动。白银累计进入射程约4.33秒，其他塔各约3.67～3.80秒，最终只造成443.68伤害，未击杀。这个特定场景说明“塔够强但覆盖不足”，不能据此推断所有其他摆法都失败。

## 材料与适用范围

- 白银：B1 + Y1 + D1。
- 孔雀石：E1 + Q1 + G1。
- 星彩红宝石：R2 + R1 + P1。
- 白银、星彩和孔雀石合成后，原材料变石，不能继续把这些材料塔的减速、攻速、毒伤或伤害算在阵容里；需要另保留表中辅助塔。
- 核心全部使用1～2级基础材料，属于第10波前规则上可构成的组合。但本次没有模拟完整的1～9波建造、保留决策与随机出石概率，不保证任意种子都能获得这些塔和MVP分布。
- 2倍速改变现实等待时间，不改变游戏秒下的输出、移速比例或击杀结果。

# 缺失机制补全记录

更新：2026-09-09。规则版本：`2018-source-mobile-alpha-6-mechanics`。

本轮承接[上一版差异审计](current-original-differences.md)，补全可以从固定脚本确认的单人规则。参考版本仍是2018年历史快照，不能等同于当前游廊版本。英雄技能与多人合作继续按首版范围暂缓；第10波Boss保留用户指定的800生命。

## 塔技能与命中时序

- 普通攻击与附加箭加入追踪弹道，使用NPC弹速。普通攻击保留目标，直到死亡、失去视野或离开射程；附加箭选择附近其他敌人，绕过普通攻击闪避及命中被动。附加箭命中时读取当时攻击力；来源已经合成消失时，网页版保留发射时数值与旧行归属。
- 闪电链从上一跳1000单位内选择最近未命中目标，每0.2秒跳一次，最多5个目标；前一跳目标已死亡则终止。叉状闪电先处理主目标，再选1000单位内最多4个额外目标，恢复Lua的最远优先顺序。
- 灼烧改为每个敌人、每种光环modifier独立计时；同名重叠不重复叠伤。离开光环后保留1秒modifier；三档分别每0.5/0.5/2秒结算30/160/5000魔法伤害，到期不再跳伤。
- 不同等级减速、减甲独立保存2秒到期时间，低级命中不再续期高级效果。不同等级同时存在时的强度暂继续取最强值，详见下文边界。
- 翡翠魔像恢复1%石化触发：辅助施法约0.5秒后开始，持续5秒；1000单位内朝向来源累计2秒的敌人石化3秒并受到额外50%物理伤害。面向由当前路径方向近似。
- 斯里兰卡之星恢复命中周围300单位、3秒50%减速与禁止治疗；埃及金恢复800单位贪婪标记，击杀5%概率获得10倍金币；虾美石恢复攻击开始3%伪随机、自我缴械5秒。
- 暴击、不可侵犯、自我缴械采用原技能声明的伪随机分布。其余显式随机技能沿用独立抽样。
- 友方魔免光环开始实际保护塔免受敌方缴械。基础碧玺不影响魔免目标，升级碧玺可以；二、三级折翼允许魔免目标，仍排除远古。狂暴获得魔免后也遵循相同光环权限。
- MVP、自身攻击增幅、猫眼与号角的攻击百分比在本移植中相加；MVP魔抗公式继续采用上一版明确记录的移植约定，没有据此新增穿免。

## 石板

恢复八类、三级石板：诱捕、瘴气、洪流、嗥叫、酸雾、麻痹、恐吓、虚无。本轮五颗候选满足对应两种材料后，选中空格、打开操作框即可建造；五颗候选全变石并开波。石板独立保存，不阻挡寻路，同格不能再建宝石。

三块同类同级石板排成横、竖或斜向相邻直线，会自动在中间升一级，最高三级。敌人进入128单位触发范围后施法，10秒冷却。

- 诱捕为追踪网、5秒定身，高级增加目标数量。
- 瘴气为线性弹道，等级改变长度、速度与减速；减速随时间衰减。
- 洪流延迟1.6秒，在目标位置周围256单位造成150魔法伤害并附带眩晕/减速。按实际施法事件只计150，未把未执行伤害的thinker误叠为额外伤害。
- 号角对施放当时范围内友塔提供10秒攻击增幅；酸雾留下持续区域减甲。
- 麻痹为可弹跳眩晕弹；恐吓以1500单位/秒追踪弹到达后施加范围增伤和加速；虚无施加减速及魔法易伤，其KV没有配置真正的虚无状态，不额外赋予物理免疫。
- 石板触发还有24%概率检查目标附近500单位的海豹，触发8000魔法伤害、最多10次后续弹跳的连环霜冻。它不是海豹普攻的随机被动。伤害归属海豹；洪流伤害归属石板，石板不参与塔MVP评选。

图鉴保存配方和各级技能说明；手机操作框与桌面入口共用石板组件。

## 存档与仍需验证的边界

alpha-6保存随机攻击、已复制技能、弹道、独立减益、石板、区域、石化、随机Boss以及历史伤害。可迁移alpha-3/4/5；alpha-5保留原MVP与统计。旧护国与天然祖母绿没有保存生成时信息，只能在迁移时用当前状态初始化一次；之后刷新不再重抽。旧版战斗中途更新不能重建已经漏算的技能或过去的伤害。

本轮补全了缺失机制的执行路径，但不声称已逐点复制Source 2。尚保留的差异包括：护甲公式仍用0.06、MVP与折翼减抗的历史组合、不同等级减速/减甲强度叠加、移速上下限、辅助单位转身与施法顺序、弹道来源被合成后的存续、寻路碰撞以及过量伤害统计。瘴气衰减和光环边缘时序按30Hz模拟近似。当前硬免疫开关仍不能解释用户回忆的全免疫波穿透，不添加无证据的95%或99%上限。

英雄、多人、竞速、付费/皮肤和Dota美术音效不在本轮范围。自然抽石的后期通关率仍需要实战和逐波伤害反馈；机制回归通过不等于整局数值验收。

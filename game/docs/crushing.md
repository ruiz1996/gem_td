# 敲碎降级并保留

日期：2026-09-08。用户要求在单颗保留旁增加“敲碎”，随机降级，并明确“越接近的等级概率越高”。此操作已经接入桌面侧栏和手机宝石操作弹窗。

## 操作规则

1. 仅限准备阶段、本轮五颗全部建成后，选择一颗尚未保留的2级及以上基础宝石。
2. 操作框显示“敲碎并保留”和各目标品质的概率；浏览概率不消耗随机数。1级按钮禁用，已保留塔、石头及合成塔不提供敲碎。
3. 点击后只随机一次，保持宝石种类、实例ID、位置和放置序号，品质严格降低，最低为1级。
4. 其他四颗本轮候选原地变石；此前已保留的塔不受影响，棋盘占用和路线不变。
5. 自动关闭手机操作框、开始当前准备的波次，沿用普通保留的开波流程。此前的准备阶段暂停不阻止开波；倍速保留，后台仍暂停。
6. 完成后不能再敲碎本轮结果。战斗中仍允许配方合成，但敲碎不作为战斗操作开放。

## 概率

目标品质越接近当前品质，概率越高；没有保持原品质或变成石头的结果。

| 原品质 | 降级结果与概率 |
| --- | --- |
| 1级 | 不可敲碎 |
| 2级 | 1级100% |
| 3级 | 2级66%，1级34% |
| 4级 | 3级50%，2级30%，1级20% |
| 5级 | 4级50%，3级25%，2级15%，1级10% |

2～5级来自项目已缓存的2018 Lua中 `gemtd_downgrade_stone`，并符合本次用户要求。代码按降1、2、3……级保存权重，界面和随机抽取共用该配置。

当前随机建造最高5级，融合产生的6级已是保留宝石，不会成为可敲碎的本轮候选。引擎为6级候选保留了兼容分支：降至5/4/3/2/1级的概率为45/25/15/10/5%。这是遵循本次“越近越高”要求的项目补充，区别于历史Lua中6级等概率降级的兜底；不新增6级随机出石或战斗敲碎入口。

# 当前实现与原版差异清单

核查日期：2026-09-08。当前代码：`b5fe62d098f4df6a2f642904dea4f7b3d280b087`，规则版本`2018-source-mobile-alpha-5-original-mvp-stats`。

对照的是资料作者保存的[2018脚本快照712f6a2](https://github.com/clementbera/Website/tree/712f6a2d0f68ea4049e8923917311f8d1a44dfc8/GemTD-Generation/scripts)，不是当前游廊客户端。本次只检查和保存证据，没有修改游戏规则。

## 总体判断

基础建造、普通波数值、经验概率、合成材料和MVP主体已实现；合成资格、动态生成属性、若干关键技能、怪物主动/被动能力和引擎结算仍有明显差异。部分差异使当前游戏更容易，另一些使输出更低，不能用统一调血量来补偿。

本轮把原Lua的38条常规配方与13条隐藏配方逐条比较，**51条材料组合均相同，但隐藏配方的使用条件不相同**。92种塔有17种带“脚本未还原”提示，其中11种仅缺装饰特效；另有6种的提示确实包含战斗/经济技能。天然祖母绿、友方魔免光环等遗漏没有被这个提示完整覆盖，因此这些数量不能当作完成率。

可复查的属性、配方清单与当前引擎隔离实验保存在[机器可读证据](../reports/original-differences.json)。固定场景不代表自然抽石、不代表原客户端实测，也不是通关平衡评估。

## 一、已确认的优先修正项

### D01：隐藏配方错误地允许跨波积攒材料

- 原版：`gemtd_merge_secret`的13条隐藏配方只在`build_curr[player_id]`本轮五颗候选中检查，然后由`merge_tower1`完成本轮保留。已保留宝石池的后续配方检查只遍历常规`gemtd_merge`。
- 当前：所有51条配方合并进同一`RECIPES`，`materialPool`只区分候选/已保留，没有区分常规/隐藏资格。因此13条隐藏配方都可用历轮保留材料在战斗中合成。
- 实验：逐条构造已保留材料，在战斗中调用真实`recommend`和`combine`，13/13均成功。
- 影响：可长期收集某一种类的1～5级宝石直接合成超级塔，也可跨波收集黑曜石、玛瑙、虾美石、燃烧之石、歌鸾石的隐藏材料。这显著改变获得难度与时机。
- 依据：[原Lua1276、4411、8270附近](https://github.com/clementbera/Website/blob/712f6a2d0f68ea4049e8923917311f8d1a44dfc8/GemTD-Generation/scripts/vscripts/addon_game_mode.lua#L4411)；当前`data.ts:288`、`engine.ts:497–581`。

### D02：护国神异石固定1攻击，缺少随机攻击和附加魔法伤害

- 原版普通单人合成路径在生成时随机设置基础攻击为30～1024；本轮直接合成路径为1～1024。竞速分支的1～1024不应误当作普通单人常规合成参数。
- 原`tower_ranjin`在攻击命中后把本次攻击事件伤害再作为一笔魔法伤害交给`ranjin`处理。
- 当前仅读取NPC占位攻击值1，没有动态攻击实例字段，也不执行`ranjin`；隔离命中记录为物理1、魔法0。其折翼光环仍在运行，不能说整塔完全无效。
- 依据：[Lua8162](https://github.com/clementbera/Website/blob/712f6a2d0f68ea4049e8923917311f8d1a44dfc8/GemTD-Generation/scripts/vscripts/addon_game_mode.lua#L8162)、8604、9690；技能KV3244；当前`data.ts`塔构建和`engine.ts:tick`。

### D03：天然祖母绿没有复制周围技能

- 原版普通合成后，从220单位内友方远程塔的可偷取技能池中，随机取得最多3种不同技能；实际列表由`stealable_ability_pool`限制。攻击、射程和攻速复制代码已注释，不能把注释当作当前原版效果。
- 当前只是80攻击的普通单体塔，没有复制动作、复制结果存档或动态技能列表，图鉴也没有相应缺失提示。
- 依据：[Lua8183–8245](https://github.com/clementbera/Website/blob/712f6a2d0f68ea4049e8923917311f8d1a44dfc8/GemTD-Generation/scripts/vscripts/addon_game_mode.lua#L8183)。

### D04：镇家之石有数据，但正常游玩无法获得

- 原版同一轮出现至少4颗同种5级宝石时，选择升两级会生成镇家之石。
- 当前融合限制结果品质不得超过6，4颗5级只提供“2颗融合升一级”；镇家之石没有普通配方，所以该获取途径被阻断。
- 实验：4颗D5加1颗B1的本轮候选，`fuseOptions`只返回`[2]`。
- 依据：[Lua4351、4913–4924](https://github.com/clementbera/Website/blob/712f6a2d0f68ea4049e8923917311f8d1a44dfc8/GemTD-Generation/scripts/vscripts/addon_game_mode.lua#L4913)；当前`engine.ts:462`。

### D05：减速/减甲将不同来源压成一个状态，还会错误延长强效果

- 原版B1/B6、P1/P6使用不同名字的modifier，分别有2秒持续时间。
- 当前敌人只有一个`slow/slowUntil`和一个`pierce/pierceUntil`，取最强值但用每次命中重新刷新统一到期时间。
- 实验：先B6施加480减速，约1.5秒后B1命中；原B6应到期的2.067秒之后，2.167秒时仍保留480，并被延长到3.533秒。P6的64减甲也能被P1同样延长。
- 不同等级是否逐项相加还要锁定引擎规则，但“低级命中延长高级modifier”的状态合并问题可以直接确定。只使用最强值也可能低估不同等级共存时的效果。
- 依据：KV`SlowTarget1..6`、`modifier_jianjia_target1..6`；当前`engine.ts:795–808`。

### D06：光环的技能免疫权限没有逐项执行

| 项目                       | 原版配置                                                  | 当前行为与影响                                                                                      |
| -------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 深海珍珠、红珊瑚、一家之石 | `tower_chenmoguanghuan`给附近友方远程塔魔法免疫           | 数据有`immunity:true`，引擎从未读取该字段；保护作用未生效。当前也没有敌方缴械，两个缺口暂时互相遮掩 |
| 帕拉伊巴碧玺               | 基础`tower_bixi`不包含魔免敌人；升级`tower_bixi2`明确包含 | 当前两个等级的减甲都作用于魔免目标，抹掉了升级权限差异                                              |
| 二/三级折翼                | KV明确允许魔免敌人进入光环，包含减速属性                  | 当前移动结算对魔免敌人直接丢弃全部光环，二/三级折翼的减速也一并丢失                                 |

依据：技能KV4371、4450、4486、6878；当前`data.ts:266`、`engine.ts:auraAt/hit`及847行。这里是可定位的目标权限差异；不代表已证明铀235或古代鸡血石在用户回忆版本中的穿免原因。

## 四、引擎规则与仍待验证的部分

### 护甲公式的历史版本不一致

当前`physicalMultiplier`采用`1−0.06A/(1+0.06|A|)`。Valve的[7.07官方更新](https://www.dota2.com/duelingfates?l=schinese)将正护甲减伤系数从0.06改成0.05，[7.20官方更新](https://www.dota2.com/720?l=schinese)又改了公式。按2018快照对应时期的7.07后公式比较：100点物理打10/20/30护甲，当前造成62.5/45.455/35.714，而0.05公式为66.667/50/40。正护甲下当前会更少伤害。

这是新发现的历史基线问题，应锁定实际目标客户端再更改；负护甲、攻防类别倍率和自定义引擎覆盖不能仅凭这段正护甲更新说明补全。当前还没有模拟NPC的`CombatClassAttack/Defend`类别，具体倍率需要进一步核实。

### 移动、选敌、射程与攻速

- 当前八向A*、七路标和32预置石头与已交叉核对的社区地图一致；不是Source 2导航、单位碰撞、射程边缘判定的完整复现。
- 原Lua每0.1秒下移动命令，距路径点32单位内即可换点，并带±5单位偏移；当前必须走到格点中心，再沿下一段插值。当前飞行单位直接连接七个路标。
- 原Lua定时检查终点400单位范围内的敌人并结算撞城；当前走到最终坐标才漏怪。终点附近有效输出时间可能不同，不能只用地图总长度认定接触时间相同。
- 当前每次攻击按敌人已走路程优先，没有原生攻击目标锁定、攻击获取范围、转向/弹道飞行模型。
- 当前最低速度固定0.35格/秒（44.8单位/秒），攻击间隔按`interval/(1+攻速加成/100)`计算，没有原生攻速/移速上下限、状态抗性与状态净化框架。这些均需目标客户端实测。

### MVP与其他增益组合

上一轮恢复了MVP正计分评选、每级攻击增幅/敌方减抗、满级圆形攻击光环、等级继承等主体。仍有这些边界：

- MVP减抗采用独立来源乘法，其他折翼减抗则直接减魔抗数值，两种路径没有统一成历史modifier结算；需要核验同属性、多来源和负魔抗。
- 黑色猫眼石与MVP在KV都使用`DAMAGEOUTGOING_PERCENTAGE`，当前猫眼倍率与MVP倍率相乘。例如MVP10加猫眼为2×1.5=3倍；按同属性相加会是2.5倍。是否按同一属性统一累加应作专门核验，不能以当前3倍直接宣称与原引擎一致。
- 附加箭、攻击基数溅射是否包含各MVP/猫眼增幅、免疫穿透权限，仍需区分攻击事件与Lua`ApplyDamage`路径。
- 当前实际伤害先限制在剩余生命内，再逐笔向下取整作为MVP计分；原版使用`OnTakeDamage`事件数值，历史客户端是否含溢出尚未重放验证。
- 合成后保留旧毒、累计生涯伤害和冷却，以及稳定的并列顺序，均为已说明的移植约定。原版销毁材料、创建新实体。

具体实现和限度见[MVP文档](mvp.md)。MVP主体恢复不能单独解决整套历史伤害系统的所有差异。

## 五、有意保留的产品差异

这些已有用户要求或项目范围依据，不作为需要擅自改回的错误：

- 单人、2D棋盘、安卓浏览器运行，暂不做英雄技能和多人合作；这会移除原英雄提供的增益或主动手段。
- 第10波Boss生命按用户确认从1260降为800；其他默认Boss的基础生命仍采用历史单人缩放。
- 手动选择合成材料，手机弹窗操作，石头直接替换建造，保留/敲碎后自动开波。
- 战斗中禁止建造/拆石改变路径，允许不改变占用的合成。
- 暂停、倍速、本地存档、每波分类型伤害和历史回看。
- 6级候选敲碎有自定义的近级高概率兜底；当前正常建造最高5级，该分支正常游玩不可达。

石板合成/升级/触发和金币消费系统属于仍未完成的功能，不等同于用户明确取消。英雄与合作的暂缓、无尽的未覆盖应分别记录。

## 六、已经对齐的部分

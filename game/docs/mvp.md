# MVP成长、光环与合成继承

日期：2026-09-08。来源：用户在当前任务新增的玩法设计，属于项目自定义规则；不将其当作2018原版脚本事实。用户明确要求多个MVP光环互相叠加，并与塔自身MVP加成叠加。

同日后续研究发现原`tower_mofaN`还包含800范围敌方减魔抗光环，不能将本页的全伤害加成视为原版成长的等价还原。源码、免疫关系和验证限制见[免疫核查](immunity-audit.md)。本页仍记录用户已确认且正在运行的自定义规则。

## 每波评选

- 每波正常结算（全部敌人已击杀或漏过，玩家仍存活）后授予一次MVP，包括最终胜利波。中途失败不授予未完成波次的MVP。
- 对已保留且仍为塔的实例按本波实际伤害从高到低评选，满10级塔直接跳过，直到第一座未满级塔；候选宝石和石头不参与。
- 获奖塔增加1级MVP，最高10级。比较的是本波伤害，不是累计伤害或击杀数。
- 同伤害时按放置序号，再按实例ID升序确定。若未满级塔全部为0伤害，也按并列规则选第一座，遵循“顺延到第一个未满级塔”的要求；若没有未满级塔或没有塔，则不授予。
- 伤害按抗性与免疫结算后实际扣除的生命计算，不计溢出伤害。下一波开始时重置本波伤害，累计伤害保留。
- 波次历史保存获奖时的塔种类、ID、位置、伤害和升级后等级，之后合成不会改写旧获奖记录。

## 增伤与光环

| 项目 | 规则 |
| --- | --- |
| MVP初始等级 | 0级 |
| 自身增伤 | 每级全伤害+10%，10级仍保留自身+100% |
| 满级效果 | 10级产生MVP光环，同时退出后续评选 |
| 光环范围 | 相邻八格：上下左右及四个对角格；不包含自己的格子，不是8格半径 |
| 光环数值 | 每座相邻满级塔提供全伤害+100% |
| 叠加 | 多个光环与自身MVP按百分比相加；相邻满级塔也互相受益 |

MVP伤害倍率 = `1 + (自身等级 × 10 + 相邻MVP光环数量 × 100) / 100`。

例如自身3级，旁边两座满级塔，总增伤为30%+100%+100%=230%，即造成原伤害的3.3倍。自身10级且旁边两座满级塔，总增伤300%，为4倍。自己的光环不重复作用于自己。

统一伤害入口应用一次MVP倍率，覆盖普通攻击、多重攻击、暴击、毒伤、灼烧、闪电、叉状闪电和纯粹溅射；不把溅射的MVP倍率再乘第二次。不会增加治疗量、减速数值、减甲、射程或攻击速度，也不绕过免疫。原有增伤光环和技能计算完成后，MVP倍率作为独立伤害倍率应用。

持续伤害每次实际生效时，按其当前归属塔的MVP及相邻光环计算。光环只由仍为塔且已保留的10级实例提供，材料变石时立即停止提供。

## 合成继承

1. 成品继承实际选中材料的MVP等级总和，最高10级。未选中的同类塔不转移等级。
2. 同时汇总这些材料的本波伤害、累计伤害和击杀数，避免战斗中合成丢失贡献；其他材料变石并清零这些数据，不重复计算。
3. 尚未结束的毒伤归属改为成品，后续伤害计入成品。原始毒伤数值和剩余次数不重置。
4. 保留成品位置塔的攻击冷却，沿用此前合成时序；敌人位置、路径、出怪计时及暂停/倍速不重置。
5. 满级成品立即提供光环，并在当前波结束时退出MVP评选。
6. 同品质融合也只继承实际消耗的副本；其他本轮未选中候选变石。正常新建候选的MVP为0，不会通过普通建造凭空获得MVP。
7. 预览显示各材料等级、相加过程和封顶结果；取消或验证失败不转移等级与伤害。

## 界面

- 桌面塔详情和手机宝石操作框共用MVP统计组件，显示等级、是否退出评选、自身增伤、光环数量与增伤、本波/上波伤害、累计伤害和击杀。
- 宝石列表标出MVP等级或光环；合成材料选项同时显示坐标、实例ID和MVP等级。
- 波次结算提示和波次情报展示MVP结果。地图以金色边框标记有MVP的塔；放大后显示等级。选中满级塔时高亮相邻八格。
- 面板中的“基础攻击”仍为塔原始攻击数值；MVP全伤害增幅在单独区域显示，避免混同基础属性、实际命中伤害和技能伤害。

## 存档

当前版本为`2018-source-mobile-alpha-4-mvp`，增加塔实例的`mvpLevel`、`waveDamage`、历史MVP记录和开始评选波次。有效等级为0～10，波内伤害必须为非负有限数；新版本存档缺失或损坏这些字段时拒绝载入。

上一版本`2018-source-mobile-alpha-3`可明确迁移：保留游戏进度、塔、随机状态与其他属性，MVP初始化为0，旧历史不追补MVP。准备阶段续玩可从本波开始评选；战斗中续玩因旧存档没有本波分塔伤害，跳过残余半波评选，从下一完整波开始。恢复提示会说明起始波次。旧毒伤来源已变石的情况保留其伤害效果，但不给石头累计MVP伤害。

其他更早或未知版本仍按原有兼容限制处理。MVP等级、伤害和光环会随正常存档继续保存；不会在刷新时重新授奖。

## 验证与限度

- 65项自动回归全部通过，新增17项MVP测试：逐波排名与满级连续顺延、并列/零伤害、最终波与失败、八格边界、叠加公式及真实命中、各种伤害类型、免疫和溢出、合成继承及毒伤转移、融合只计消耗材料、存档确定性、旧版迁移和损坏数据。
- 类型检查、修改源码lint及GitHub Pages生产构建通过；既有Phaser分包体积提示仍存在。
- 手机390×844下，9级蓝宝石邻接两个光环显示总增伤290%；320×568下，材料列表显示各自MVP等级，替换钻石后预览从`9+2+10`变为`9+2+3`，成品均正确封顶10级，确认/取消可见。
- 固定场景第一波由前方满级钻石完成击杀，结算跳过满级塔，按并列顺序使9级蓝宝石升到10级。波次情报保留获奖塔位置与获得光环记录。
- 手动选用3级钻石合成白银，未选中的两座满级钻石保留，白银继承10级并显示自身100%加两个光环200%；刷新后三个光环塔及波次记录恢复。
- 恢复1271×920桌面视口后，塔详情与相邻八格高亮正常，浏览器无控制台错误。

界面测试使用独立本地端口和忽略目录中的固定数据场景，复用真实界面与引擎，不进入发布包。它验证MVP交互与结算，不是自然获得10级的通关或整体难度证明；尚未进行安卓真机验证。

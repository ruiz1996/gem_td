# 原版MVP与每波伤害统计

更新：2026-09-08。当前规则版本：`2018-source-mobile-alpha-5-original-mvp-stats`。

用户要求先恢复原版MVP，再通过逐波伤害观察后续平衡。此前alpha-4的“全伤害、八格光环、合并材料本波贡献”自定义规则已被本页规则替代；旧设计可从Git历史查询。本轮没有改变物理/魔法免疫开关或添加假设的95%/99%减伤上限。

## 攻击、法术与叠加

自身攻击倍率与收到的满级攻击光环相加：

`攻击倍率 = 1 + 自身等级 × 0.1 + 范围内其他满级塔数量`

例如自身3级，受到两个满级光环时，攻击倍率为3.3。290单位圆形范围覆盖周围20个整数格中心：八个相邻格、轴向两格及(±2,±1)/(±1,±2)；不包含两格对角位置。

原KV使用的是`DAMAGEOUTGOING_PERCENTAGE`，不是`TOTALDAMAGEOUTGOING_PERCENTAGE`。[开发者的攻击结算实验](https://github.com/Elfansoer/dota-2-lua-abilities/blob/master/scripts/vscripts/lua_abilities/_test/modifier_test_attack.lua)区分了它们。网页版将MVP攻击增幅应用于普攻、多目标攻击和基于攻击的溅射，且只乘一次。固定毒伤、灼烧、闪电不再直接乘攻击增幅，通过敌方减魔抗光环间接受益。攻击光环不增加治疗、攻速、射程等数值。

减抗叠加按KV修饰器身份处理：

- 1～9级同等级只保留一份，不同等级共存。
- 每座10级塔分别贡献一份，其敌方减抗和友方增幅均明确标记`MODIFIER_ATTRIBUTE_MULTIPLE`。
- 满级友方攻击光环也可以相互叠加。属性语义见[ModDota技能KV说明](https://moddota.com/abilities/ability-keyvalues)。

**移植约定，仍待历史客户端实测：**各MVP减抗来源按独立乘法组合。令现有魔抗和其他塔减抗结算后的承伤系数为B，则魔法伤害系数为`B × ∏(1 + 0.07 × 来源等级)`。同级低级来源先去重，满级逐塔计算。例如基础魔抗25%，两个10级MVP来源得到`0.75 × 1.7 × 1.7 = 2.1675`倍魔法承伤。`-70`并不在这里解释为直接减70个百分点。历史KV能证实数值、范围和多实例属性，不能单独证明历史引擎完整结算顺序。其他塔已有减抗的实现保持原样。

魔免敌人不受MVP减抗，物免敌人仍可受减抗。当前硬免疫规则仍然有效；本轮不宣称解决了铀235或古代鸡血石的历史穿免问题。

## 合成与伤害归属

- 原材料等级之和封顶10；只计算实际选中的副本。
- 成品本波实际伤害和MVP计分归零，旧材料伤害保留在统计原行，标记“已合成，不参与评选”。
- 合成前施加的毒仍按原数值和剩余次数跳伤，归属原材料行，不给成品加计分。原脚本销毁材料的具体持续技能生命周期尚未客户端复现；网页版继续保留既有毒效果，仅明确区分来源，避免凭空增加成品贡献。
- 旧波次快照不会因后来合成、材料变石、开下一波而改变。当前波旧材料的毒仍可继续更新其原行。
- 累计生涯伤害和累计击杀仍合并，供单塔详情参考；它们不参与MVP评选。成品冷却沿用原位置塔，迷宫占用、敌人、出怪时钟和暂停状态不变。
- 正计分并列时按建造顺序、实例ID稳定排序。原Lua使用`pairs`，没有可证实的固定平局规则，这是网页版的可复现约定。

## 伤害统计界面

右上角图表按钮和操作设置中的“每波伤害统计”都可以打开面板；游戏失败/胜利面板也有入口。手机仍以整张地图为游玩区，统计按需弹出。打开时暂停，关闭时恢复打开前的暂停状态。

- 默认显示当前波；准备阶段默认上一已完成波，可切换本局历史波次。
- 每行保留塔名、位置、实例ID、当时MVP等级、实际伤害、占比、物理/魔法/纯粹分项、逐笔取整计分、击杀和评选结果。
- 可按实际伤害或MVP计分排序；0伤塔也显示，便于检查免疫波。
- 实际伤害包含小数，最多显示3位；正数小于0.001时显示`<0.001`。MVP计分为整数。原版逐笔取整可能出现实际掉血但计分0，界面明确分开。
- 统计实际扣血，不计过量击杀伤害。本版沿用此口径；原脚本接收`OnTakeDamage`，但该历史客户端对溢出值的处理未单独验证，因此不声称MVP伤害数完全逐点复刻。
- 记录总伤害、战斗时间和完成/进行中/失败状态。失败当前波保留，且不补发MVP。

## 存档迁移

alpha-4存档保留MVP等级并切换到新效果；alpha-3存档初始化MVP为0。已有游戏进度、塔、随机状态和生命等保留。

战斗中从旧版续玩，旧本波总伤害按“未分类”保留，已消耗材料和逐笔取整结果无法重建，本波标记部分统计并跳过MVP评选，下一波完整计分。准备阶段迁移可从即将开始的波次完整计分。旧历史MVP结果保留，但没有原先未保存的分塔明细，不补造数据。

新存档同时保存当前报告与各历史报告，并校验数值、类型、当前阶段/波次关联以及MVP获奖行，损坏数据拒绝载入。刷新不会重置当前贡献或重复颁奖。

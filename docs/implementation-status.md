# 首版制作记录

更新日期：2026-09-08。

最新功能：单颗保留增加“敲碎并保留”，随机降低品质，越接近当前品质概率越高；种类与位置不变，其余候选变石，随后自动开波。桌面与手机共用规则和概率展示，48项回归及生产构建通过。原版2～5级概率、兼容分支和本地手机尺寸实操见[敲碎记录](../game/docs/crushing.md)。

最新操作更新：点击“保留并开始本波”后直接出怪，手机弹窗自动关闭；桌面使用同一命令。战斗中支持打开配方、手动选择材料并合成，其余材料原地变石。新增3项规则回归，当前共43项通过；390×844浏览器尺寸下使用隔离的固定材料场景实操，验证暂停存档开波、战斗合成确认/取消和2×恢复。测试详情见[手机交互记录](../game/docs/touch-interaction.md)，该场景仅用于交互验证，不作为平衡或真机验收。

最新界面更新：按用户新反馈移除手机常驻操作区，改为全图游玩、点选位置后按“操作”弹出建造/宝石/合成框，完成后返回地图。此前固定底部/右侧面板已替代。完成390×844、844×390、320×568浏览器尺寸实操，包括五次独立建造、暂停状态恢复、取消预览及手动替换重复材料后合成。详细设计和验证限度见[手机交互记录](../game/docs/touch-interaction.md)。

最新本地版本已依据2018 Lua/NPC配置校准，完成手机尺寸浏览器实操。完整证据见[原版规则核对与本地测试](../game/docs/original-rules-audit.md)。用户随后授权推送这些修改；公开测试入口为[GitHub Pages](https://ruiz1996.github.io/gem_td/)，上线状态以仓库Actions为准。

## 本次实现

地图修正版已于 2026-09-07 发布成功：[打开试玩](https://gemtd-mobile-lab.k410094675.chatgpt.site)。Sites 版本号 2；源提交 `7d85ff82392524df2ce630a770b541b8f036ce89`。部署服务确认 succeeded；访问范围仍为仅本人。原版本1使用25×19暂定地图，现已替换。

游戏源码位于 `game/`，使用 TypeScript、Phaser 3.90.0 和 Sites/Vinext 应用外壳。规则、数据与表现分离，所有程序生成图形都是游戏棋盘和单位标记，未复制 DOTA 2 素材。

- 地图修正版：37 × 37 单人布局，七个路线点、两块9×9禁建区、32块预置石头、八方向 A*。详见[考据报告](research/original-map.md)。
- 每轮放置 5 颗，保留一颗、同品质融合或本轮配方合成。
- 准备阶段拆石；战斗阶段固定阻挡集合。
- 合成默认选材、手动替换、确定成品位置及取消；预览暂停。
- 50 波推进、飞行、隐形、护甲、魔抗及基础免疫机制。
- 主要宝石的攻击、毒、减速、减甲、溅射、多重攻击、灼烧和光环。
- 图鉴和波次信息、倍速、本机存档、后台暂停和胜负结算。

## 验证结果与限度

- 33项规则与地图回归通过，新增经验品质、动态出怪、Boss伤害、毒层、纯粹溅射和高攻速计时测试。
- 50波状态测试使用超高伤害与全图显隐夹具，只验证结束分支，不证明正常通关。
- 当前5个固定种子中心布局策略均在第10波失败；此前16–17波结果已被旧规则淘汰。策略没有合理迷宫或配方规划，不能据此断言原版数值有误，后期平衡仍待验证。
- 类型检查与静态生产构建、修改文件lint执行验证。
- 已在桌面浏览器的390×844、844×390尺寸实操放置、融合、暂停、倍速、首波结算、拆石、图鉴与刷新续玩；高级配方手选由规则测试覆盖。未进行安卓真机测试。

打包说明：本机官方 Bash 包装与 Node 目录暂存调用失败，使用原生 PowerShell 按同一 Worker 归档规范打包。脚本验证入口和非链接目录，使用新暂存目录，不递归删除已有文件；归档包含 `dist/server/index.js`、客户端产物和 `dist/.openai/hosting.json`。没有更改访问范围。

# 当前升级曲线：全击杀条件

整理日期：2026-09-08。计算基线：游戏代码提交 `290fcae0cec7d30dd501f2c6884629c3fb736763`。本次仅整理当前实现，不调整游戏数值；不是对原版完整规则的再次考证。

这里的等级指界面“宝石品质 Lv.”，控制后续建造时的出石品质概率。升级不会把地图上已有宝石自动升阶；同品质融合是另一项机制。

## 结论与前提

从全新游戏、经验0开始，全程击杀全部怪物。仅“全击杀”无法确定唯一升级波次，因为通关速度会影响后续普通波怪物数量。

- **每波快速全灭**：每波都在严格小于90秒模拟时间内全灭。Lv.2/3/4/5分别在第 **7/10/16/20波** 达成，属于当前规则下全击杀的最早边界。
- **始终没有增怪奖励**：未出现连续三波快速全灭，普通波一直为5只。Lv.2/3/4/5分别在第 **8/11/20/26波** 达成，属于全击杀的最晚边界。
- 混合快慢通关时，升级波次处于对应边界内，具体取决于此前已增加多少只普通怪物。

| 达到等级 | 累计经验门槛 | 每波快速全灭：升级时点 | 首次按新概率建造 | 始终无增怪奖励：升级时点 | 首次按新概率建造 |
| --- | --- | --- | --- | --- | --- |
| Lv.1 | 0 | 开局 | 第1波 | 开局 | 第1波 |
| Lv.2 | 200 | 第7波，第7/7只 | 第8波 | 第8波，第5/5只 | 第9波 |
| Lv.3 | 550 | 第10波，第1/1只 | 第11波 | 第11波，第3/5只 | 第12波 |

| Lv.5 | 1700 | 第20波，第1/1只 | 第21波 | 第26波，第4/5只 | 第27波 |

经验达到门槛的击杀发生时立即升级，无需等本波结束。但战斗中不能建造，所以新概率首次用于下一波的准备阶段。Lv.5是当前品质等级上限，之后经验仍累计。

## 直接采用的代码规则

| 项目 | 当前规则 |
| --- | --- |
| 累计经验门槛 | 0、200、550、1050、1700；升级不扣经验 |
| 逐级新增经验 | Lv.1→2需200，2→3需350，3→4需500，4→5需650 |
| 普通怪经验 | 第1–9波每只5；11–19波每只10；21–29波每只15；31–39波每只20；41–49波每只25 |
| Boss经验 | 第10、20、30、40、50波各1只，每只300 |
| 额外过波经验 | 无 |
| 普通波初始数量 | 5只 |
| 快速全灭条件 | 零漏怪，且从开波到清场的模拟时间严格小于90秒 |
| 增怪 | 连续三波满足条件后，后续普通波数量加1，连续计数归零；Boss波也参与连续计数，但自身始终只有1只 |
| 未达快速条件 | 连续计数归零，之前增加的怪物数量保留 |
| 暂停与倍速 | 暂停期间不累计模拟时间；2×加快模拟推进，90秒判断仍使用模拟时间，不是现实秒数 |

本题假定无漏怪，因此不执行漏怪导致的减怪规则。在每波都快速全灭时，第w波普通怪数量为：

`5 + floor((w - 1) / 3)`

Boss波按1只覆盖；其余波本波经验等于怪物数量乘单只经验。逐波相加即可得到累计经验，在每次击杀后比较升级门槛。

来源为当前 [经验与出怪配置](../game/lib/game/data.ts) 中的 `WAVES`、`MOBILE_RULES`，以及 [规则引擎](../game/lib/game/engine.ts) 中的 `startWave`、击杀经验结算与清场连续计数。现有 [规则回归](../game/tests/original-rules.test.ts) 覆盖经验门槛及三次快速全灭增怪。本表通过直接导入当前配置逐只累加计算，并核对引擎中的更新顺序；没有用正常战斗通关来证明曲线可达。

## 维护说明

2026-09-08新增MVP后，经验门槛与击杀经验未变化，上述全击杀快慢边界仍适用。MVP会增强伤害，可能影响是否在90秒模拟时间内全灭，从而间接影响增怪及实际升级波次；不会直接奖励额外经验。

当经验门槛、单只经验、Boss分布、增怪条件或初始数量发生变化时，应重新计算本表。保留开波、战斗合成与材料选择交互没有改变上述升级参数。真实无英雄布局能否保持每波90秒内全灭，仍属于后续平衡验证范围。

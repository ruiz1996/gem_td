# 宝石 TD 安卓版

目标：参考 DOTA 2 自定义游戏《宝石 TD》，制作能在安卓手机上完整运行的单人 2D 棋盘塔防游戏。优先保证规则正确、数值合理，再完善美术表现。

当前阶段：已实现首个可运行试玩版，源码位于 [game/](game/README.md)。历史资料已固定到 2018 年快照；完整原版还原、后期平衡和安卓实机验收尚未完成。

手机试玩发布目标：[GitHub Pages](https://ruiz1996.github.io/gem_td/)（以 Actions 部署成功为准）。手机自动启用独立触屏界面，支持横竖屏；操作设置可手动切换模式。

仓库：[ruiz1996/gem_td](https://github.com/ruiz1996/gem_td)。发布与本地测试步骤见 [GitHub Pages 文档](docs/github-pages.md)。

## 维护约定

- 用户确认的需求以需求文档为准；外部资料不能覆盖已确认的规则。
- 新资料记录来源 ID、完整链接、查阅日期、版本和使用限制，并保存简要事实摘要，避免只留链接。
- 严格区分“来源中有记载”“已对照目标版本核实”“本项目改动”。资料日期不等于游戏版本。
- 不把魔兽版、手游版、网页衍生版的数据混入 DOTA 2 基线。
- 缺失数值写“待核实”，不能用猜测或零值冒充原版数据。
- 需求或数值发生变化时，同步更新相关文档和决策记录；以后再同步实现与验证结果。
- 本资料库保存整理摘要与引用，不是外部网站全文镜像，也不保证链接永久有效。
